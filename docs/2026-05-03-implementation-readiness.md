# 오늘 우리 반 구현 준비 노트

참고 설계 문서: `docs/2026-05-03-homeroom-community-dashboard-design.md`

## 구현 방향

- 첫 버전은 교사 중심 대시보드와 제한된 학생 참여 흐름을 함께 가진 단일 웹앱으로 시작한다.
- 프런트엔드는 React + Vite + TypeScript로 구성한다.
- 데이터 저장소는 아직 붙이지 않고, 도메인 모델과 계산 로직을 먼저 순수 TypeScript 함수로 분리한다.
- UI는 `오늘 우리 반` 대시보드를 첫 화면으로 두고, 자리 배치, 칭찬 기록, 안건, 규칙 합의로 이동하는 구조를 사용한다.
- 학생 참여 화면은 교사용 화면과 라우팅/컴포넌트 경계를 분리한다.

## 우선 구현 단위

1. 학생 명부와 학급 선택
   - `classId` 기준 데이터 분리
   - `studentId` 내부 식별자 사용
   - 학생 참여 입력값인 학급 번호는 정규화 후 `studentNumber`와 비교

2. 오늘 우리 반 대시보드
   - 새 안건 수
   - 마감 임박 투표
   - 최근 7일 칭찬 공백 학생
   - 자리 조건 충돌
   - 점검일이 가까운 학급 약속

3. 자리 배치 시뮬레이터
   - 행/열 기반 좌석표
   - 비활성 좌석과 고정 좌석
   - 강한 조건과 약한 조건 평가
   - 충돌 조건을 숨기지 않고 설명 목록으로 표시

4. 칭찬·격려 기록장
   - 교사 전용 칭찬 기록 추가
   - 학생 제보는 검토 대기 상태로 저장
   - 기록 부족 시 억지 문구 생성 대신 기록 추가 안내

5. 안건·규칙 합의 흐름
   - 안건 상태 enum과 규칙 후보 상태 enum 분리
   - 회의 결과를 규칙 후보로 전환
   - 투표 중복은 `classId + activityId + studentId` 조합으로 차단
   - 확정 규칙은 학급 약속과 점검일을 가진다.

## 민감 정보 경계

- 자리 조건, 관계/갈등 관련 운영 메모, 칭찬 공백 정보는 학생 화면에 노출하지 않는다.
- 익명 활동에서도 중복 방지 키는 저장하지만 교사용 공개 화면에는 제출자 정보를 표시하지 않는다.
- 학생 제보와 안건은 교사 검토 전 공개 목록에 반영하지 않는다.
- 보관 상태 학급은 교사용 읽기 전용으로 전환하고 학생 참여 활동은 자동 종료한다.

## 테스트 기준

- 학생 번호 입력 정규화와 명부 매칭

- 투표 중복 제출 차단

## 2026-05-03 구현 반영

- 교사용/학생용 모드 전환 화면을 추가했다.
- 교사용 기능을 대시보드, 자리 배치, 칭찬 기록, 회의 안건, 규칙 합의 화면으로 분리했다.
- 자리 배치 화면에서 추천 재생성, 직접 좌석 변경, 미사용 좌석 토글, 앞자리/분리 조건 추가를 지원한다.
- 칭찬 기록 화면에서 교사 칭찬 추가, 칭찬 공백 확인, 학생 제보 승인/보류, 주간 문구 편집을 지원한다.
- 회의 안건 화면에서 참여 활동 열기, 교사 안건 추가, 안건 상태 변경, 규칙 후보 전환을 지원한다.
- 규칙 합의 화면에서 후보 생성, 의견 수집/투표/투표 종료/확정, 학생 투표 집계 반영, 확정 약속 저장을 지원한다.
- 학생 화면에서 참여 코드와 학급 번호로 안건 제출, 칭찬 제보, 규칙 투표를 처리한다.
- 투표는 `classId + activityId + studentId` 기준으로 중복 제출을 막는다.
