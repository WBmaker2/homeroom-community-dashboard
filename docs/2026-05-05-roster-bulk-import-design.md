# 학생 명부 일괄 등록 설계

## 배경

학급 설정 화면은 학생을 한 명씩 등록하고 수정할 수 있다. 실제 담임교사가 처음 앱을 사용할 때는 학급 전체 명단을 입력해야 하므로, 번호와 이름을 반복해서 수기 입력하는 과정이 가장 큰 초기 사용 부담이 된다.

이 기능은 기존 단건 등록의 번호 정규화, 중복 검증, 보관 학급 읽기 전용 정책을 그대로 유지하면서 여러 학생을 한 번에 추가하는 흐름을 제공한다.

## 목표

- 교사가 명단을 여러 줄로 붙여넣어 학생을 일괄 등록한다.
- CSV 형식의 `번호,이름,표시명` 데이터를 지원한다.
- 번호/이름 누락, 중복 번호, 기존 명부와의 충돌을 등록 전에 미리 보여준다.
- 문제없는 행만 등록하고, 오류 행은 건너뛴다.
- 등록 결과를 성공 수와 건너뜀 수로 안내한다.

## 입력 형식

한 줄이 학생 한 명이다.

지원 형식:

```text
1 홍길동
2 김서연 서연
3,박민준,민준
4	최하늘	하늘
```

- 쉼표가 있으면 CSV 행으로 처리한다.
- 쉼표가 없으면 공백 또는 탭으로 번호, 이름, 표시명을 나눈다.
- 표시명은 선택값이며 비어 있으면 이름을 사용한다.
- 제목 행 `번호,이름,표시명`은 자동으로 건너뛴다.

## 검증 규칙

- 학생 번호는 기존 `normalizeRosterNumber`로 정규화한다.
- 정규화된 번호가 비어 있으면 오류이다.
- 이름이 비어 있으면 오류이다.
- 현재 학급에 이미 같은 번호가 있으면 오류이다.
- 붙여넣은 데이터 안에서 같은 번호가 두 번 나오면 두 번째 이후 행은 오류이다.
- 보관 학급에서는 일괄 등록 버튼을 비활성화한다.

## 처리 방식

일괄 등록은 미리보기와 실행으로 나눈다.

1. 교사가 명단을 붙여넣는다.
2. `미리보기`를 누르면 등록 가능 행과 오류 행을 보여준다.
3. `등록 실행`을 누르면 등록 가능 행만 현재 학급에 추가한다.
4. 실행 후 입력창과 미리보기는 초기화한다.

학생 `studentId`는 기존 단건 등록처럼 클라이언트에서 생성한다. 한 번에 여러 명을 만들 때는 기준 시각과 행 번호를 더해 서로 다른 ID를 만든다.

## 화면 배치

학급 설정의 `학생 등록` 패널 아래에 `명부 일괄 등록` 패널을 추가한다.

- 안내 예시는 짧게 둔다.
- 입력 textarea
- `미리보기` 버튼
- 등록 가능 수, 오류 수
- 오류 행 목록
- `등록 실행` 버튼

## 테스트 기준

- CSV/공백/탭 입력을 파싱한다.
- 제목 행을 건너뛴다.
- 기존 명부 중복과 입력 내부 중복을 오류로 표시한다.
- 등록 가능 행만 현재 학급에 추가한다.
- 보관 학급에서는 일괄 등록을 실행할 수 없다.
