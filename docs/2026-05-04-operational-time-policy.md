# 운영 날짜와 활동 마감 정책 설계

## 배경

현재 앱은 MVP 구현 과정에서 `todayIso`, 화면 날짜, 안건 제출 마감일, 투표 마감일, 학급 약속 점검일 일부가 `2026-05-03` 기준 고정값으로 들어가 있다. 이 상태에서는 날짜가 지나도 대시보드 신호와 학생 참여 가능 시간이 실제 수업일과 맞지 않을 수 있다.

## 목표

- 앱을 여는 시점의 현재 시간을 `todayIso`로 사용한다.
- 교사용 헤더 날짜를 현재 날짜 기준으로 표시한다.
- 새 안건 제출 활동의 기본 마감은 생성일 기준 7일 뒤 18:00으로 잡는다.
- 새 규칙 투표 활동의 기본 마감은 생성 당일 18:00으로 잡되, 이미 18:00 이후라면 다음 날 18:00으로 잡는다.
- 새 학급 약속 점검일의 기본값은 생성일 기준 7일 뒤 09:00으로 잡는다.
- 신규 샘플 데이터의 열린 활동과 점검일도 앱 시작 시점 기준으로 보정한다.
- 저장된 기존 데이터는 교사가 의도한 날짜일 수 있으므로 불러오기 때 자동으로 바꾸지 않는다.

## 비목표

- 서버 시간 기준 강제
- 교사별 시간대 설정
- 활동 마감일을 직접 고르는 상세 UI
- 저장된 기존 활동의 마감일 일괄 보정
- 학생 개인 기기와 교사 브라우저 간 실시간 동기화

## 정책

### 현재 시간

`src/domain/timePolicy.ts`를 추가해 시간 계산을 한곳에 둔다.

- `getCurrentHomeroomIso(now = new Date())`
- `formatKoreanDateLabel(isoDate)`
- `createDefaultAgendaClosesAt(baseIso)`
- `createDefaultVoteClosesAt(baseIso)`
- `createDefaultRuleCheckDate(baseIso)`

### 기본 마감

```txt
안건 제출 활동: 생성 시각 기준 7일 뒤 18:00
규칙 투표 활동: 생성일 18:00, 단 현재가 18:00 이후면 다음 날 18:00
학급 약속 점검일: 생성일 기준 7일 뒤 09:00
```

기본값은 교사가 빠르게 활동을 열 수 있게 하기 위한 운영 편의값이다. 추후 활동 설정 UI를 만들면 이 값을 교사가 수정할 수 있게 확장한다.

### 샘플 데이터

저장 데이터가 없는 첫 실행에서는 샘플의 열린 투표 활동과 규칙 후보 마감, 학급 약속 점검일을 현재 시점 기준으로 보정한다. 저장 데이터가 있는 경우에는 저장된 날짜를 그대로 유지한다.

## 구현 단위

1. `src/domain/timePolicy.ts`
   - 날짜 라벨, 기본 마감 계산 함수 추가
2. `src/state/useHomeroomState.ts`
   - 고정 `todayIso` 제거
   - 현재 시점 기준 `todayIso` 상태 유지
   - 새 샘플 스냅샷 날짜 보정
3. `src/features/teacher/TeacherShell.tsx`
   - 헤더 날짜를 `state.todayIso` 기준으로 표시
4. `src/features/teacher/views/AgendaView.tsx`
   - 안건 제출 활동 마감일을 정책 함수로 생성
5. `src/features/teacher/views/RulesView.tsx`
   - 투표 마감과 점검일 기본값을 정책 함수로 생성
6. 테스트
   - 시간 정책 함수 단위 테스트
   - 학생 참여 UI 테스트의 활동 마감일을 현재 시점과 무관하게 열려 있도록 조정

## 확인 기준

- 앱 코드에 새 활동 생성을 위한 `2026-05-03` 고정 마감이 남지 않는다.
- 대시보드 헤더는 앱 실행 날짜를 표시한다.
- 새 안건 제출 활동은 기본 7일 뒤 18:00에 닫힌다.
- 새 투표는 기본 당일 18:00 또는 다음 날 18:00에 닫힌다.
- 기존 저장 데이터는 불러오기 때 날짜가 변하지 않는다.

## 구현 기록

- `src/domain/timePolicy.ts`에 한국 시간 기준 현재 시각, 날짜 라벨, 기본 마감 계산 함수를 모았다.
- `src/state/useHomeroomState.ts`에서 `todayIso`를 앱 실행 시점 기준으로 초기화하고 1분 단위로 갱신한다.
- 저장 데이터가 없는 첫 실행 샘플만 열린 투표 활동, 규칙 후보 투표 마감, 학급 약속 점검일을 현재 정책값으로 보정한다.
- 저장된 스냅샷을 불러올 때는 기존 날짜 필드를 자동 보정하지 않는다.
- 교사용 안건 제출 열기, 규칙 투표 열기, 규칙 확정, 칭찬 기록, 학생 제출은 사용자 액션 시점의 최신 시간을 사용한다.
- 규칙 확정의 기본 점검일은 선생님이 직접 수정하지 않았다면 확정 클릭 시점 기준으로 다시 계산한다.
