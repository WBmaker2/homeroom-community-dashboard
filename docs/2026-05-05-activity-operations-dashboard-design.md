# 활동 운영 대시보드 설계

## 배경

기존 설계는 학생 참여 활동에 시작/종료 상태를 두고, 종료된 활동은 새 제출을 받지 않으며, 교사가 특정 제출 기록을 삭제해 학생이 다시 참여할 수 있게 한다고 정의했다. 현재 구현은 안건 화면과 규칙 화면에서 활동을 열 수 있고 학생 화면에서 제출을 막을 수 있지만, 교사가 활동별 운영 상태와 제출 기록을 한곳에서 다루는 화면은 부족하다.

또한 교사용 헤더의 `학생 링크 복사`는 첫 번째 열린 활동을 기준으로 링크를 만든다. 활동이 여러 개 열려 있으면 어떤 링크가 복사되는지 명확하지 않아 실제 수업 운영에서 혼란이 생길 수 있다.

## 목표

- 교사가 현재 학급의 학생 참여 활동을 한 화면에서 확인한다.
- 활동별 학생 참여 링크를 정확히 복사한다.
- 활동을 종료하거나 다시 열 수 있다.
- 특정 제출 기록을 삭제해 1회 참여 활동의 재참여를 허용한다.
- 익명 활동은 교사용 화면에서도 학생 이름과 번호를 노출하지 않는다.

## 비목표

- 활동 마감일을 직접 수정하는 상세 설정 UI
- 제출 내용 편집
- 삭제된 제출의 복구
- 서버 기반 실시간 동기화
- 학생별 영구 계정 또는 강한 인증

## 화면 배치

활동 운영은 교사용 사이드바에 `활동 운영` 메뉴를 추가해 별도 화면으로 제공한다. 대시보드의 열린 참여 활동 영역은 요약과 진입 버튼 역할만 맡고, 실제 운영 작업은 활동 운영 화면에서 처리한다.

활동 운영 화면은 두 영역으로 구성한다.

1. 활동 목록
   - 활동 제목, 유형, 참여 코드, 상태, 익명 여부, 1회/여러 번 제출 여부, 마감일, 제출 수를 표시한다.
   - `링크 복사`, `종료`, `재열기` 버튼을 제공한다.
   - 보관 학급에서는 모든 조작 버튼을 비활성화한다.

2. 제출 기록
   - 선택한 활동의 제출 기록을 최신순으로 표시한다.
   - 비익명 활동은 학생 표시명과 번호를 보여준다.
   - 익명 활동은 `익명 제출`로 표시하고 학생 이름과 번호를 보여주지 않는다.
   - 제출 내용, 투표 선택, 제출 시각을 표시한다.
   - `제출 삭제` 버튼으로 해당 제출만 삭제한다.

## 상태 변경 규칙

- `종료`는 활동의 `status`를 `closed`로 바꾼다.
- `재열기`는 활동의 `status`를 `open`으로 바꾼다.
- 재열기는 기존 `closesAt`이 지난 활동까지 강제로 연장하지 않는다. 마감일이 지난 활동은 학생 제출 게이트에서 계속 차단된다.
- 보관 학급에서는 활동 상태 변경과 제출 삭제를 할 수 없다.
- 대시보드와 활동 운영 모두에서 `열림` 판단은 `status`뿐 아니라 `opensAt`, `closesAt`을 함께 반영한다.

## 제출 삭제 규칙

- 삭제 대상은 `submissionId` 하나이다.
- 제출 삭제는 참여 제출 기록을 제거하고, `ruleVote`인 경우 대상 후보의 집계를 1씩 되돌린다.
  - `agree` 또는 `needsRevision` 선택 값이 있으면 해당 값만 1만큼 감소한다.
  - 감소 값은 음수가 되지 않도록 바닥을 0으로 제한한다.
- `agendaSubmission`/`praiseReport` 파생 데이터는 기존 기록을 유지하는 방식으로 일단 보수적으로 남겨 둔다.
  - 이 동작은 규칙안건, 칭찬 기록의 참조 무결성을 보존하기 위한 선택이다.
- 1회 참여 활동의 중복 차단은 제출 기록 기준이므로, 해당 학생의 제출을 삭제하면 다시 참여할 수 있다.

## 학생 화면 규칙

- 활동 코드가 존재하지만 활동이 종료되었거나 마감이 지났으면 종료 안내를 보여준다.
- 제출 버튼은 종료/마감/보관 학급이면 비활성화한다.
- 교사는 활동 운영 화면에서 정확한 활동별 링크를 복사해 학생에게 공유한다.

## 접근성과 편의성

- 링크 복사와 상태 변경 결과는 `role="status"` 메시지로 안내한다.
- 활동 목록은 버튼이 있는 스캔 가능한 행 형태로 유지한다.
- 삭제 버튼은 `제출 삭제`처럼 동작이 명확한 문구를 쓴다.

## 테스트 기준

- 교사용 활동 운영 화면에서 활동별 링크를 복사할 수 있다.
- 교사가 활동을 종료하면 학생 제출 버튼이 비활성화되고 새 제출이 차단된다.
- 종료한 활동을 재열면 마감 전 활동은 다시 제출할 수 있다.
- 1회 참여 활동의 제출을 삭제하면 같은 학생이 다시 제출할 수 있다.
- 익명 투표 활동의 제출 기록에는 학생 이름이나 번호가 노출되지 않는다.
- 보관 학급에서는 활동 운영 조작 버튼이 비활성화된다.
