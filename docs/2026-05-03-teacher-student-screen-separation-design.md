# 교사용/학생용 화면 분리 설계

## 배경

현재 앱은 오른쪽 위 `교사용/학생용` 전환 버튼으로 화면을 바꾼다. 이 구조는 빠른 시연에는 편하지만, 실제 수업 상황에서는 학생이 교사용 화면으로 바로 이동할 수 있다. 교사용 화면에는 학급 설정, 학생 명부, 백업, 안건 검토, 규칙 확정 등 담임 권한 기능이 있으므로 학생 참여 화면과 분리해야 한다.

## 목표

- 교사용 화면과 학생용 화면의 진입 URL을 분리한다.
- 학생 화면에는 교사용 메뉴와 화면 전환 버튼을 노출하지 않는다.
- 교사용 화면은 PIN 잠금 해제 후에만 렌더링한다.
- 학생은 참여 코드 또는 공유 링크로 바로 활동에 들어간다.
- 기존 localStorage 저장/백업 구조는 유지한다.

## 비목표

- 서버 인증
- 계정 기반 로그인
- 학생 개인 기기 간 실시간 동기화
- 강한 보안 저장소

현재 앱은 프론트엔드와 localStorage만 사용하는 MVP다. 교사용 PIN은 실수 방지와 화면 분리를 위한 잠금 장치이며, 브라우저 개발자 도구까지 막는 강한 보안 장치는 아니다. 실제 배포에서 외부 학생 기기까지 안전하게 운영하려면 서버 저장소와 인증을 별도로 붙여야 한다.

## 라우트 구조

```txt
/              진입 선택 화면
/teacher       교사용 잠금 및 교사용 대시보드
/student       학생용 참여 코드 입력 화면
/join/:code    학생용 참여 링크, 참여 코드 자동 입력
```

## 교사용 흐름

1. 교사가 `/teacher`로 접속한다.
2. 교사용 PIN이 없으면 `교사용 비밀번호 설정` 화면을 먼저 보여준다.
3. PIN을 설정하면 현재 브라우저 세션에서 교사용 화면이 열린다.
4. PIN이 이미 있으면 `교사용 잠금 해제` 화면을 보여준다.
5. PIN이 맞으면 교사용 대시보드를 렌더링한다.
6. 교사용 헤더의 `잠그기` 버튼을 누르면 다시 잠금 화면으로 돌아간다.

교사용 화면에 제공할 공유 기능:

- 현재 열린 학생 활동 코드 확인
- `학생 링크 복사` 버튼
- 복사 링크 형식: `/join/WARM-62`

## 학생용 흐름

1. 학생은 교사가 공유한 `/join/:code` 링크를 연다.
2. 참여 코드가 자동 입력된 상태로 학생 화면이 열린다.
3. 학생은 자기 학급 번호를 입력한다.
4. 활동이 열려 있으면 선택 또는 내용을 입력하고 제출한다.
5. 제출 후 자기 번호 기준의 참여 기록만 본다.

학생 화면에서 보이면 안 되는 것:

- 교사용 사이드바
- 학급 설정
- 학생 명부 편집
- 데이터 보관/백업
- 교사용 잠금 해제 링크 또는 화면 전환 버튼

## 상태 저장

기존 앱 데이터 저장은 유지한다.

- 앱 데이터: `homeroom-community-dashboard:v1`
- 교사용 PIN: `homeroom-community-dashboard:teacher-pin:v1`
- 현재 탭 잠금 해제 상태: `homeroom-community-dashboard:teacher-unlocked:v1`

PIN은 localStorage에 저장하고, 잠금 해제 상태는 sessionStorage에 저장한다. 브라우저 탭을 닫으면 다시 잠금 해제가 필요하다.

## 구현 단위

### `App.tsx`

- 모드 전환 버튼 제거
- URL 기반 라우트 판별
- `/teacher`는 `TeacherAccessGate`로 보호
- `/student`, `/join/:code`는 학생 화면만 렌더링
- `/`는 교사용/학생용 진입 선택 화면 제공

### `TeacherAccessGate.tsx`

- PIN 최초 설정
- PIN 잠금 해제
- 세션 잠금 상태 관리
- 잠금 해제 후 교사용 화면 렌더링

### `TeacherShell.tsx`

- `잠그기` 버튼 추가
- 학생 참여 링크 복사 버튼 추가
- 학생 링크는 첫 번째 열린 활동 코드를 기준으로 생성

### `StudentParticipation.tsx`

- `initialCode` prop 추가
- `/join/:code`에서 참여 코드 자동 입력
- 학생 화면에는 교사용 이동 UI를 두지 않음

## 접근성 및 사용성

- PIN 설정/해제 실패 메시지는 `role="status"`로 알린다.
- 학생 참여 링크가 없을 때도 `/student`로 직접 들어가 코드를 입력할 수 있다.
- 학생 링크 복사가 실패하면 링크 텍스트를 화면에 보여 교사가 직접 복사할 수 있게 한다.
- 모바일에서는 교사용 헤더 버튼과 학생 카드가 세로로 안정적으로 접히게 한다.

## 테스트 계획

- `/student`와 `/join/:code`에서 교사용 메뉴가 보이지 않는다.
- `/teacher`는 PIN 설정 또는 잠금 해제 전에는 교사용 메뉴가 보이지 않는다.
- PIN 설정 후 교사용 화면이 열린다.
- 잠금 해제 세션이 있으면 교사용 화면이 바로 열린다.
- 학생 링크에서 참여 코드가 자동 입력된다.
- 기존 학급/학생 등록, 백업 가져오기 테스트가 `/teacher`에서 계속 통과한다.
