# 학급 설정 기능 설계 기록

참고 설계 문서: `docs/2026-05-03-homeroom-community-dashboard-design.md`

## 목적

교사가 샘플 데이터에 의존하지 않고 직접 학급을 등록하고, 학생 명부를 관리한 뒤 자리 배치, 칭찬 기록, 안건, 규칙 합의 기능을 사용할 수 있게 한다.

## 첫 구현 범위

### 학급 관리

- 학급 등록
  - 학급명과 학교급을 입력해 새 학급을 만든다.
  - 새 학급은 `active` 상태로 생성된다.
  - 새 학급을 만들면 즉시 선택된 학급으로 전환한다.
- 학급 수정
  - 현재 선택된 학급의 이름, 학교급, 상태를 수정한다.
- 학급 보관
  - 보관 상태 학급은 읽기 전용 전환을 위한 준비 상태로 둔다.
  - 현재 구현에서는 상태값을 바꾸고, 학생 참여 활동을 자동 종료하는 정책을 이후 저장소 연동 단계에서 강화한다.
- 학급 삭제
  - 마지막 남은 학급은 삭제하지 않는다.
  - 학급을 삭제하면 해당 학급의 칭찬 기록, 안건, 규칙 후보, 학급 약속, 학생 참여 활동, 제출 기록을 함께 제거한다.
  - 삭제된 학급이 현재 선택 학급이면 남아 있는 첫 학급으로 전환한다.

### 학생 명부 관리

- 학생 등록
  - 학급 안에서 쓰는 번호, 이름, 표시명을 입력한다.
  - 번호와 이름은 필수다.
  - 표시명이 비어 있으면 이름을 기본 표시명으로 사용한다.
- 학생 수정
  - 번호, 이름, 표시명을 수정한다.
  - 다른 기능은 학생을 `studentId`로 참조하므로 번호와 표시명 변경은 기존 기록을 깨뜨리지 않는다.
- 학생 삭제
  - 학생을 삭제하면 자리 고정 배정, 수동 배정, 자리 조건, 칭찬 기록, 학생 참여 제출 기록을 함께 정리한다.
  - 학생이 제출한 안건은 학급 회의 흐름을 보존하기 위해 삭제하지 않고 제출자 연결만 제거한다.

## 데이터 모델 방향

기존 `homeroomClass: sampleClass` 단일 구조를 다음처럼 확장한다.

```text
homeroomClasses: HomeroomClass[]
activeClassId: string
homeroomClass: activeClass
classSeatMaps: Record<classId, SeatMap>
classSeatingConstraints: Record<classId, SeatingConstraint[]>
classManualAssignments: Record<classId, SeatAssignment[]>
```

칭찬 기록, 안건, 규칙 후보, 학급 약속, 참여 활동, 제출 기록은 전역 배열로 보관하되 화면에 넘길 때는 현재 학급의 `classId`로 필터링한다. 기존 화면에서 쓰는 setter는 현재 학급 범위만 교체하는 래퍼로 제공해 다른 학급 데이터가 섞이거나 사라지지 않게 한다.

## 화면 구조

교사용 내비게이션에 `학급 설정`을 추가한다.

- 학급 목록과 새 학급 등록
- 현재 학급 정보 수정
- 학생 등록 폼
- 학생 명부 편집 목록

명부가 비어 있는 학급에서는 자리 배치와 칭찬 기록 화면이 바로 작업을 시작하지 않고 학급 설정에서 학생을 먼저 등록하도록 안내한다.

## 검증 기준

- 새 학급을 등록하면 학급명과 학생 수가 교사용 화면에 반영된다.
- 학생을 등록하면 학생 수, 자리 배치 선택지, 칭찬 기록 선택지에 반영된다.
- 학생 정보를 수정하면 화면에 표시되는 이름과 번호가 바뀐다.
- 학생을 삭제하면 학생 수가 줄고, 해당 학생의 좌석/조건/칭찬/제출 연결이 정리된다.
- 마지막 학급 삭제는 차단된다.
- 학급 삭제는 해당 학급의 운영 데이터를 함께 제거한다.

## 구현 반영

- 교사용 내비게이션에 `학급 설정` 화면을 추가했다.
- `useHomeroomState`를 단일 샘플 학급에서 `homeroomClasses + activeClassId` 구조로 확장했다.
- 학급 등록, 수정, 보관, 삭제 차단/삭제 정리를 구현했다.
- 학생 등록, 수정, 삭제와 학생 삭제 시 관련 자리/칭찬/제출 연결 정리를 구현했다.
- 명부가 비어 있는 학급에서 자리 배치와 칭찬 기록 화면이 안내 상태를 보여주도록 보호했다.
- 학급 설정 흐름을 UI 테스트로 보호했다.
